# Ограничения и что реально проверялось

Дата прогона: 2 ноября 2026. Машина прогона: macOS 15.8.1, Apple Silicon (arm64). Это не чистая учебная установка: WorkAI уже был в «Программах», Git 2.56.0 и Python 3.9.6 уже были в PATH.

## Проверено здесь

- `python3 -m unittest discover -s tests -v` — 14 тестов, все прошли.
- Правила «копировать / обновить / оставить файл участника» совпадают в Python и в bash. Самопроверка `install-macos.sh --self-check` прошла.
- Повторный BASIC-запуск во временную папку сохранил дописанную строку в `НАЧАЛО.md`. Папка `~/Documents/AI-Managers-v2` при этом не создавалась.
- `--dry-run` на этой машине ничего не записал, увидел пакет с верной SHA-256, получил код 200 от `https://workai.su/download` и напечатал **ГОТОВО**, потому что WorkAI уже установлен. Для компьютера без WorkAI тот же сценарий даёт **ЧАСТИЧНО**: так устроена таблица статуса, отдельным прогоном без программы она не подтверждалась.
- Файл с кириллическим путём `День_1/Заметка.md` скопировался, повтор не затёр правку. Поддельная SHA-256 отклонилась.
- Архив `docs/files/AI-Managers-v2-1.0.0.zip` совпал с `course-pack/ZIP.SHA256`. В списке файлов нет папки ведущего.
- В портале, промптах и учебном пакете нет присваиваний токенов и частных IP-адресов.
- В браузере открыты `http://127.0.0.1:4174/prompts.html`, день 3, страница скачивания и главная на ширине 390px. Восемь промптов показались из отдельных JS-файлов. Ссылка WorkAI была `https://workai.su/link/prompt?text=` с percent-encoding, параметр `text` читался по-русски. На странице скачивания видна SHA-256 `4663d47b4044062604567998824e5b581cae0612fce053ffe5e5fa5e0a1c10f4`. День 3 описывает карточку MCP и не содержит адреса и ключа.
- Кнопка «Скопировать» в этом встроенном браузере не получила доступ к буферу. Страница выделила текст и написала, что нужны Ctrl+C или Cmd+C. В обычном Chrome или Safari после щелчка буфер обычно доступен. Это здесь не подтверждалось. Сам переход по ссылке внутрь приложения WorkAI не выполнялся.

## Не проверялось

| Сценарий | Почему |
| --- | --- |
| Чистая Windows 10 и Windows 11 | На этой машине нет PowerShell. `install-windows.ps1` не запускался. |
| macOS Intel и чистая macOS 12 | Был только этот Apple Silicon с уже стоящими программами. |
| Повтор на Windows, частичная среда, отказ администратора | Скрипт Windows не исполнялся. На Mac отказ root проверяется кодом, но процесс от root не запускался. |
| Нет прав на «Документы» | Каталог был доступен. Временная папка теста тоже. |
| Нет GitHub | Пакет брался с диска, скачивание по `download.url` не устраивалось. Сайт WorkAI при dry-run ответил. |
| Обрыв загрузки и нехватка места | Ветки статуса есть в самопроверке. Диск не заполнялся, загрузка не обрывалась. |
| BASIC и ADVANCED с реальной установкой Git, Python, WorkAI | BASIC копировал файлы во временный каталог. `brew install` и `winget install` не запускались. Формулы Homebrew в этом сеансе через `brew info` не подтверждались: при ошибке скрипт открывает страницы git-scm и python.org. |
| Живой GitHub Pages | Публикация не делалась. `portal_url` пустой. |
| `file://` в браузере | Портал смотрели по HTTP. Скрипты промптов подключены через `src`, без `fetch`, чтобы файл с диска тоже открывался. Этот способ в браузере не открывали. |
| Диалоги Gatekeeper, SmartScreen и интеллектуального управления приложениями | Скрипт их не вызывает и не отключает. Поведение окон не снималось. |

Перед занятием один раз прогоните `Setup-Course.cmd` на учебном Windows и `Setup-Course.command` на Mac без WorkAI. Пока этого нет, считать Windows-ветку готовой к классу рано.
