# Учебная система

Четыре файла ниже — единственный реестр задач, проектов, показателей и документов.
Тексты в папках `00`–`07` не должны расходиться с этими таблицами.
Учебный MCP читает те же файлы и больше ничего не выдумывает, кроме двух учебных ограничений.
Какие именно ограничения включены, участнику до разбора не объяснять: это материал ведущего.

| Файл | Содержание |
|------|------------|
| `tasks.csv` | Поручения: статус в СЭД и фактический статус |
| `projects.csv` | Портфель: как проект сдан в отчёте и что с ним фактически |
| `kpi.csv` | Показатели с разными источниками в одной строке |
| `documents.csv` | Паспорт каждого рабочего документа |
| `кэш/pmo_cache.json` | Срез, который инструмент статуса умеет отдать как есть |

Колонка `path` в `documents.csv` задана от корня папки `v2/`.
`case_id` пустой у документов компании в целом.
