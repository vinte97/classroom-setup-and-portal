## Инструменты

1. `get_project_status` для `PRJ-ERP` и для `PRJ-SUP2`.
2. `list_tasks` с `case_id` = `CASE-ERP-001`.
3. `get_task` для `T-ERP-01`, для `T-HR-PAY` и для `T-ERP-99`.
4. `get_warehouse_balance` для `K12`.
5. `list_kpi` без фильтра — только если нужно сверить готовность ERP с другими показателями.

Записать по каждому вызову: что вернулось, дата среза, совпало ли это с файлами, что сделать с ответом «сведений нет» и «нет полномочий».
