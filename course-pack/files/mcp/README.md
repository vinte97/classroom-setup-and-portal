# Учебный MCP

Сервер только читает `09_Учебная_система`. Писать, платить и отправлять письма он не умеет.
Запуск из этой папки:

```bash
python3 server.py
```

В WorkAI сервер добавляется как локальная команда `python3` с аргументом — полный путь к `server.py`.
Протокол: JSON-RPC, заголовок `Content-Length`, версия `2024-11-05`.

Инструменты: `list_tasks`, `get_task`, `get_project_status`, `get_warehouse_balance`, `list_kpi`.

Проверка без чата:

```bash
python3 selfcheck.py
```

Ограничения инструментов разбирает ведущий по материалам в `10_Материалы_для_преподавателя`. В этот файл они не выписаны, чтобы пакет дня 3 не подсказывал ответ.
