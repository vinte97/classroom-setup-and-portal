# День 3 · подключение SeverProm MCP Lab

На этом листе нет адреса сервера и нет ключа. Ведущий выдаёт их каждому отдельно, не через GitHub и не через этот портал.

Локальный учебный сервер в папке `mcp` ключа не требует: он только читает `09_Учебная_система`. Как запустить его командой, написано в `mcp/README.md`. Для этой команды нужен Python (режим установки ADVANCED).

Удалённая лаборатория SeverProm MCP Lab — другой контур. Её адрес и секрет приходят в конверте или в защищённом сообщении ведущего.

## Что сделать на занятии

1. Откройте в WorkAI папку курса `AI-Managers-v2`.
2. Откройте настройки MCP так, как показывает ведущий.
3. Вставьте адрес и ключ из своей карточки. Чужую карточку не копируйте.
4. Проверьте, что видны только инструменты чтения: `list_tasks`, `get_task`, `get_project_status`, `get_warehouse_balance`, `list_kpi`.
5. Ключ не вставляйте в чат, не кладите в файлы курса и не присылайте в общий чат группы.

Ответ инструмента записывайте как отдельный источник, вместе с датой среза, которую он назвал. «Сведений нет» и «нет полномочий» — это тоже ответ, его не заменяют догадкой.
