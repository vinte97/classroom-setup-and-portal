# Участнику курса «ИИ для руководителей v2»

Компьютер готовится один раз. На занятии вы работаете в WorkAI и в папке «Документы / AI-Managers-v2». Люди и цифры в учебных файлах вымышлены.

## Установка

Windows: дважды щёлкните `Setup-Course.cmd`.

Mac: правой кнопкой по `Setup-Course.command` → «Открыть». Если система спрашивает подтверждение, это её защита. Разрешите запуск сами, если файл пришёл от ведущего.

Дальше:

1. Режим **1 / BASIC**, если ведущий не попросил Python. Режим **2 / ADVANCED** нужен к третьему дню для локального учебного сервера.
2. Прочитайте план и введите «да».
3. Дождитесь итоговой строки.

| Строка | Что это значит |
| --- | --- |
| ГОТОВО | Папка курса на месте, WorkAI найден, а в ADVANCED ещё Git и Python. |
| ЧАСТИЧНО | Папка курса на месте. WorkAI, Git или Python нужно доустановить по открывшейся странице. |
| ТРЕБУЕТСЯ ПОМОЩЬ | Позовите ведущего и покажите журнал. |

Войти в WorkAI нужно самим. Пароль скрипт не спрашивает.

## На занятии

Откройте WorkAI и папку курса. Берите файлы только из задания дня: `11_Пакеты_по_дням`. Если факта нет в приложенных файлах, пишите «не указано». Настоящие документы работодателя, пароли и ключи в чат не отправляйте.

Промпты лежат на учебном портале. Кнопка «Скопировать» и, если текст короткий, «Открыть в WorkAI». Вторая кнопка только подставляет текст. Отправляете его вы.

Портал без интернета: файл `docs/index.html` в папке, которую выдал ведущий.

## День 3

Адрес и ключ SeverProm MCP Lab выдаёт ведущий лично. На сайте курса их нет. Ключ не копируют в чат и не кладут в файлы.

Повторный запуск установки ваши правки не стирает.
