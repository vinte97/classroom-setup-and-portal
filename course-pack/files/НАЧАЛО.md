# ИИ для руководителей v2

Это учебная папка на вашем компьютере. Люди, письма и цифры в ней вымышлены.

1. Установите WorkAI с сайта, который открыл скрипт, и войдите сами. Пароль скрипт не спрашивает и никуда не записывает.
2. В WorkAI откройте эту папку.
3. На занятии прикладывайте только файлы из задания дня. Папки ведущего в комплекте нет.
4. Если факта нет в приложенных файлах, так и пишите: «не указано».
5. Настоящие документы работодателя, пароли, ключи и доступы в чат не отправляйте.

Задания лежат в `11_Пакеты_по_дням`.
Повторный запуск установки не затирает файлы, которые вы уже изменили.
