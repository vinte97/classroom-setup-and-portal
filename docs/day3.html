SeverProm MCP Lab

С этого дня ведущий выдаёт личную карточку: адрес сервера и ключ. На этом сайте их нет и в GitHub они не коммитятся.

  1. Откройте в WorkAI папку курса AI-Managers-v2.
  2. В настройках MCP вставьте адрес и ключ со своей карточки так, как показывает ведущий.
  3. Убедитесь, что видны только инструменты чтения: list_tasks, get_task, get_project_status, get_warehouse_balance, list_kpi.
  4. Ключ не отправляйте в чат и не сохраняйте в файлах курса.

Локальный учебный сервер в папке mcp — другой контур, без ключа. Он только читает реестр. Команда запуска написана в mcp/README.md и требует Python.
