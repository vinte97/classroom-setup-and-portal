Итог ЧАСТИЧНО

Учебная папка на месте, но WorkAI, Git или Python ещё нужно доустановить руками. Запустите скрипт ещё раз после установки: ваши файлы сохранятся.

Итог ТРЕБУЕТСЯ ПОМОЩЬ

Мало места на диске, нет права на папку «Документы», слишком старая система или пакет не прошёл проверку SHA-256. Ничего не чините сами, позовите ведущего и покажите журнал из папки logs.

Windows показала синее окно

Это штатная защита. Для обычного предупреждения нажмите «Подробнее», затем «Выполнить в любом случае». Скрипт SmartScreen не отключает.

Если окно называется «Интеллектуальное управление приложениями заблокировало приложение», не выключайте эту функцию на учебном компьютере: по документации WorkAI включить её обратно можно только переустановкой Windows. Позовите ведущего. Справка: установка WorkAI на Windows.

Нет интернета или не открывается GitHub

Файлы курса уже лежат рядом со скриптом. Портал — это файл index.html. Скачивать репозиторий заново не нужно.

Нет прав администратора

Папка курса их не требует. Git и Python скрипт просит поставить в профиль пользователя. Если это не вышло, откроется обычная страница загрузки.

Кнопка WorkAI пропала

Текст не влез в ссылку. Нажмите «Скопировать» и вставьте его в чат WorkAI сами.

Русские имена файлов

Папка курса называется AI-Managers-v2 латиницей. Файлы внутри могут быть на русском. Это нормально для Windows и macOS.
