Скачать WorkAI

  1. Скачайте установщик для своей системы с официальной страницы. На Windows это exe, на Mac — dmg для Apple Silicon или Intel.
  2. Пройдите мастер. Пароль в установщик курса вводить не нужно.
  3. Откройте WorkAI и войдите сами.
  4. Откройте папку «Документы / AI-Managers-v2».
  5. В чат прикладывайте только файлы из задания дня.

Кнопка «Открыть в WorkAI»

Она ведёт на страницу https://workai.su/link/prompt?text=. Клиент подставляет текст в поле ввода и сам его не отправляет. Отправка — ваша кнопка или Enter.

Документация WorkAI ограничивает ссылку workai://share/… восемью тысячами символов. Более длинный текст портал не прячет в ссылку: его можно только скопировать.

Подробности: ссылки WorkAI и быстрый старт.
