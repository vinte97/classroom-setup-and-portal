# Запасной пакет

Если на занятии нет GitHub, учебные файлы уже лежат в `course-pack/files`.

Сюда можно положить заранее скачанный zip с тем же содержимым. Скрипт возьмёт его, только если SHA-256 совпадёт с `course-pack/ZIP.SHA256`. Чужой архив будет пропущен.

Установщик WorkAI сюда не кладут. Для него есть папка `offline/workai`.
