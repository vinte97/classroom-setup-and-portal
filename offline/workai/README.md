# Локальный установщик WorkAI

Сюда ведущий может заранее положить файл, который сам скачал со страницы https://workai.su/download.

- macOS: файл `.dmg`
- Windows: файл `.exe`

Скрипт откроет этот файл обычным мастером после согласия. Тихую установку он не запускает: официальные параметры тихой установки не опубликованы. Контрольную сумму установщика скрипт не проверяет, пока её нет в документации WorkAI.

Не выключайте Gatekeeper, SmartScreen и интеллектуальное управление приложениями ради этого файла.
